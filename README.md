# 🎓 Projeto Acadêmico: [ECO.I]

Este repositório contém o código-fonte e os arquivos de um projeto desenvolvido como parte da avaliação da disciplina.

## 📚 Estrutura e Páginas

O projeto é composto por quatro arquivos principais:

| Arquivo | Tipo | Descrição |
| :--- | :--- | :--- |
| **`index.html`** | Estrutura | Página de entrada do projeto (Home). |
| **`educação.html`**| Estrutura | Página secundária focada em detalhar o tema 'Educação' (Ex: Formação, Habilidades, Conteúdo Programático). |
| **`style.css`** | Estilo | Folha de estilos responsável pelo design e layout responsivo de todo o site. |
| **`script.js`** | Interatividade | Arquivo JavaScript que adiciona funcionalidades dinâmicas (Ex: Navegação, Animações, Validação). |

## ✨ Tecnologias e Implementação

Este projeto foi construído puramente com tecnologias front-end, sem uso de frameworks externos:

* **HTML5:** Utilizado para a estrutura semântica das páginas e organização do conteúdo.
* **CSS3:** Empregado para o design responsivo, uso de Flexbox/Grid e variáveis CSS para manutenção de tema.
* **JavaScript (Vanilla):** Implementado para a manipulação do DOM e adição de interatividade.
